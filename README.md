**The Permission Door** — a short poem about agency: the power to ask and to be given. Five lines, 222 characters. Before the knock, the door is only wood; one asked question turns it into a threshold, and a yes becomes a small sun rising in a stranger's hands.

`main.py` is its deterministic runner: it writes the poem to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
